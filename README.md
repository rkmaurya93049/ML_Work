# Machine Learning Experiments & Kaggle Practice

A collection of machine-learning notebooks covering classification, regression, optimization, regularization, neural-network training techniques, and applied prediction tasks.

This repository is primarily a hands-on learning and experimentation workspace. The notebooks explore both core ML concepts and applied datasets.

Representative topics include:

- Binary classification
- Regression
- Gradient descent variants
- Regularization
- Dropout
- Early stopping
- Neural-network training experiments
- Admission prediction
- House-price prediction
- Loan repayment prediction
- Calories prediction
- Anemia detection
- Podcast-listening prediction

## Recommended Environment

Most notebooks can be explored with a standard Python data-science environment containing packages such as:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

Individual notebooks may require additional libraries depending on the model or dataset used.

## Running the Notebooks

Clone the repository:

```bash
git clone https://github.com/rkmaurya93049/ML_Work.git
cd ML_Work
```

Start Jupyter:

```bash
jupyter notebook
```

Then open any notebook and run the cells in sequence.

## Notes on Reproducibility

This repository is a learning workspace rather than a single production ML system. Because the notebooks were created across different experiments:

- dependency versions are not yet standardized;
- some datasets may come from external notebook environments;
- some notebooks may require path adjustments before running locally;
- model metrics should be interpreted in the context of the individual notebook and dataset.
