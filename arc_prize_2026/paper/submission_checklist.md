# ARC Prize 2026 Paper Track Submission Checklist

## ARC-AGI-2 submission
- [ ] Join ARC Prize 2026 ARC-AGI-2 and accept rules before the entry deadline.
- [ ] Attach the official competition dataset to the Kaggle Notebook.
- [ ] Run with internet disabled under Kaggle competition constraints.
- [ ] Confirm `/kaggle/working/submission.json` exists.
- [ ] Confirm every challenge task ID is present.
- [ ] Confirm every test output has `attempt_1` and `attempt_2`.
- [ ] Submit the notebook and record the exact Kaggle submission ID.
- [ ] Record public/private score only when Kaggle reports it.

## Paper Track writeup
- [ ] Join the Paper Track.
- [ ] Create a Kaggle Writeup documenting the actual ARC-AGI-2 submission.
- [ ] Keep final writeup at or below 1,500 words.
- [ ] Select the required track in the Writeup UI.
- [ ] Add a cover image to the Media Gallery.
- [ ] Attach a publicly accessible notebook.
- [ ] Optionally attach a public project/paper link.
- [ ] Replace all placeholders in `writeup_draft.md` with measured values.
- [ ] Include the ARC-AGI-2 submission ID so judges can match code and score.
- [ ] Address Accuracy, Universality, Progress, Theory, Completeness, and Novelty explicitly.
- [ ] Submit the Writeup before the Paper Track deadline; do not leave it as a draft.

## Research integrity
- [ ] Do not report unmeasured accuracy.
- [ ] Do not describe planned components as implemented components.
- [ ] Cite external algorithms, datasets, papers, and borrowed code.
- [ ] Open-source prize-eligible solution artifacts as required by competition rules.
